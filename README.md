# 🌍 Global Life Quality Dashboard

🔗 **Live Demo:** [Click here to view the dashboard](https://your-app-link.streamlit.app)

This project is an interactive data visualization dashboard that explores the **quality of life across different countries** using a range of measurable indicators. The goal is to help users gain insights into how life quality varies globally and over time through clear, engaging visualizations.

## 📌 Key Features

- **Visual Exploration of Life Quality** metrics:
  - GDP per Capita
  - Life Expectancy
  - Air Quality (PM2.5)
  - Unemployment Rate

## 🗂️ Project Structure

The dashboard is divided into three main sections:
1. **Global Overview** – See global trends and rankings across all metrics.
2. **Country Insights** – Focus on a specific country's performance.
3. **Deep Analysis** – Explore correlations, network relationships, and patterns among countries.

## 📊 Data Sources

- **GDP per Capita** – World Bank  
- **Life Expectancy** – Human Mortality Database  
- **Air Quality** – World Health Organization  
- **Unemployment Rate** – International Labour Organization  
- **Geospatial Info** – Country coordinates from Kaggle  

## ⚙️ Technologies Used

- **Python**
- **Streamlit**
- **Plotly**
- **Pandas**

## 📝 Notes

- The data has been cleaned, filtered (from 1980 onward), and prepared individually for each visualization to preserve quality and avoid merging issues.
- This project emphasizes **data storytelling through visualization** more than statistical modeling.
